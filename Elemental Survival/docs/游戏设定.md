# Elemental Survival — 当前游戏设计
更新：2026-11-03。本文是当前唯一有效设计依据；代码实现状态见《任务进展》。archive 内为历史记录，不得恢复其中已废弃规则；聊天中更早的相反定义同样作废。

## 游戏定位与开局
Windows 键鼠单人、三维地形建筑＋二维卡通角色的俯视角生存逃离游戏。世界主题为元素灾变中的聚落与遗迹。美术参考原图位于 references/art_direction/2026-11-02，完整功能完成后再统一打磨。角色与怪物改为原创圆润卡通轮廓，借鉴土豆兄弟的清晰辨识和周身武器，不复制其资产。

主菜单→开始游戏→选择三个技能、一把初始武器→开始逃离→暂停地图选择六个默认聚落之一→确认出生后世界开始运行。出生区域仅为苔石村、风车集镇、东岸旧街、南部农庄、荒草聚落、断桥街区；不生成野外候选点。每区在聚落内部挑选安全落脚点，确认时再次校验；不可因首选位置被占用而退回野外出生。毒/火危险区域内不能出生，内部安全桥石也不例外。最多同时装备三把武器，其余放背包。

## 核心循环和时间
探索聚落、搜刮、击杀、锻造附魔、利用危险环境、集齐核心/棱镜/齿轮三个不同关键部件，返回固定地牢入口，清理三间地牢并撤离。死亡结束本局；携带假死可抵消一次致死，恢复50%生命，隐身与加速持续8秒。目标单局40–60分钟，仍需调校。
世界周期暂定360秒、提前60秒预警、高塔8秒下陷。周期变化不强制暂停；地图、背包、商店、锻造与奖励选择暂停全部模拟。F6仅为计时调试快捷键。

## 地图与移动世界（新规则）
地图要扩大；每局聚落身份和布局重排，本局道路与聚落保持稳定。毒区、火区、高塔与补给设施按周期迁移，不得再使用单毒区/单火区左右互换的临时方案。同种元素同时存在多处区域。迁移选点必须避开聚落、世界边缘、其他区域与当前玩家，并同步画面、碰撞、危险判定、导航和地图。地图尺寸、同类区域数量、箱子数量的放大系数为实现时的可调参数，并记录实际值。

## 武器与装备
现有弧刃、追风针、震荡核三类；武器在角色周围分槽显示，攻击时有朝向与挥动/后坐反馈。当前暂不扩展武器种类。两把同星材料＋保留目标升星；三星消耗神拼图突破四星。背包可直接选武器锻造，不要求先装备；已装备材料不得自动消耗。目标保留原所在位置。
每种元素附魔最高5级，合成继承同样封顶。1星容量1种元素、2星3种、3星以上不限种类。生化服与消防服共用一个整套防护槽，分别免疫毒/火环境伤害。

## 掉落（用户最新确认）
| 来源 | 武器规则 |
|---|---|
| 普通小怪 | 0.5%掉落一星武器 |
| 精英 | 必掉一把，一星/二星各50% |
| BOSS | 必掉一把二星武器 |
| 补给/宝箱 | 暂沿用12%/25%，后续试玩调整 |
宝箱总计2%概率获得一件穿戴防护装备（不是两件各2%）。普通怪物死亡按死亡点掷对应材料：元素区内30%、区外5%；桥石虽然安全，仍属于领域内。站在区域里不凭空生成材料。

## 敌人设计方向
普通敌人须以低成本职责区分：追踪近战、蓄力冲锋、保持距离喷射。精英有清楚预警和攻击后空档。追猎型BOSS持续追踪，区域镇守型有归位边界；不同元素使用不同攻击模式、轮廓和配色，不能只增加血量、放大或换色。新增数值为可调首版，不照搬其他游戏。

## 元素区与桥梁
毒区：超大不规则硫酸池、缓慢上升毒烟、鼓泡、外围大鹅卵石、池中宽阔安全石岛、互通桥网。桥石/外岸安全，入酸液才中毒；安全处不自动回血。毒烟首先作为环境表现，不能在安全桥上额外隐形扣血。
火区：须有独立的岩岸、裂隙/熔岩、焦黑岩群和清楚的边界；火区仍按领域接触判定伤害，岩石为实体障碍，不因看到岩石就视为免伤平台，不接受单一棕色圆盘。毒区桥梁采用简洁古代石桥语言：舒缓桥拱、节奏明确的栏柱/桥墩和少量装饰，连接处留回旋空间。画面高度必须与角色落脚一致，不能只把平桥画弯却让角色悬空。
高塔采用废城堡布局：四向石拱入口、左右有顶侧廊、中央精英庭院、双出口奖励室，主塔与两座副塔形成错落轮廓。玩家可以经内院走短路，或经西廊和北侧通道绕行；建筑为多高度外观，实际行走与战斗仍在同一层，没有上下楼功能。模型实体、平面碰撞、寻路、精英和宝箱锚点共用tower_layout。塔体在原有8秒内整体下沉，结束后迁移并释放旧建筑与碰撞；精英血量、宝箱已搜刮状态沿用既有规则。廊顶和墙体遮挡玩家时局部透视，暂停时旗帜停止摆动。

## 设施、成长与终局
每村/部落至少一辆独立电量电动车；R上下车，骑行禁攻；电池给当前或附近实际车辆充电。售卖柜仅在部分聚落出现，不是每村必有。补给与宝箱应分散，房屋内部可随机生成，但不增加密集堆放。寻龙尺探测宝箱，地图不自动泄露普通箱子位置。
BOSS/宝箱强化为三选一，选项适配携带技能，可付费或免费次数刷新。技能定义与当前实现数值以 data 和 active_skills.gd 为准；未启用的其他元素/武器不进入当前制作范围。

## 当前表现规范（2026-11-03）
本轮 UI 参考位于 references/ui_forest/2026-11-02：暖纸色、木色边、森林绿主按钮、深棕文字和彩色物件图标。主菜单/备战/背包/锻造/HUD 共用原生主题，保留已有流程。锻造采用左侧配方、右侧独立滚动背包；可直接升级未装备武器。
9类角色图组（玩家、普通敌人、精英和BOSS）采用原创四方向卡通图集，迈步按真实位移推进；待机、蓄力、攻击和受击有独立表现，移动中自动射击保留步态。地图/背包暂停时动作和攻击一同暂停。
玩家弹道用青绿色拖尾与暖白亮芯，敌方弹丸用红橙外壳与亮芯。范围危险显示边界/倒计时环，冲锋显示锁定路线；这些只表现真实攻击，不改变命中规则。美术仍待玩家复核，Scenario生成服务未使用。
环境表现采用暖太阳光/偏冷环境光，进入毒、火、地牢时缓慢过渡；路灯最多同时启用四盏近景灯。毒烟为软边薄烟，火区为有冷热变化的岩壳裂隙和喷口火焰；环境粒子不附加伤害。草叶、树冠、水纹、风车和烟火随游戏暂停。桥面上的弹丸/危险预警使用与人物一致的安全表面高度，不能埋进桥板。

## 架构和验收
移动/生命/战斗/奖励与美术表现分离；一个规则只能有一个权威来源。怪物职责、武器外观、元素场景应通过独立模块扩展。节点、特效、旧场景与迁移碰撞要释放或复用，缓存须有界；不以强制GC或定时删游戏内容掩盖泄漏。每完成任务更新《任务进展》，记录改动文件、验证、未完成事项及恢复步骤。
