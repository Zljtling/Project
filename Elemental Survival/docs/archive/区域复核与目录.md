# 区域复核与目录

本轮按用户反馈修复房屋入口，扩充另外五处聚落，统一区域目录，并先将六处场景合到一个可走动的三维复核世界。元素领域和高塔区域留待用户复核后设计。

## 复核入口

按 F5，在主菜单选择“三维区域复核 · 六处聚落”。也可以打开 `scenes/regions/region_review.tscn` 按 F6。

| 操作 | 按键 |
| --- | --- |
| 移动 / 快行 | WASD / 按住 Shift |
| 镜头远近 | 鼠标滚轮 |
| 切到对应区域入口 | 数字 1—6 |
| 检查房内箱子 | 靠近按 E |
| 返回当前区域入口 | Home |
| 返回主菜单 | Esc |

数字对应：1 风车集镇、2 东岸旧街、3 南部农庄、4 荒草聚落、5 断桥街区、6 苔石村。六处场景放在同一块地面上，也可以沿连接道路步行过去。复核布局固定，便于对比；完整试玩的每局地图重排规则不变。

本入口用于检查造型、比例、进屋、遮挡、路线与箱子位置，不发放正式奖励。用户已复核通过；主菜单“开始游戏”现进入 `scenes/game_run.tscn`，已接入这些三维聚落、正式战斗和毒元素区域，详见《正式场景接入与毒元素区域》。

## 房子为何进不去

原房屋地板碰撞面比室外高 0.1 米，当前角色没有跨台阶逻辑，正常从地面走过去会被卡住。旧测试从高于地板的位置开始，漏掉了这个情况。新增测试复现了四种房屋的入口问题。

现在所有房屋的物理地板与室外齐平，仅把可见地板抬高 8 毫米以防闪烁。下部立面横梁也分成门洞两侧，避免视觉上像封住门口。屋顶和朝向镜头的墙面继续按进入/离开切换，隐藏不删除实体墙体。

码头、栈桥和替代木桥也使用齐平的通行面，避免同样的碰撞门槛问题。水域和断桥缺口仍阻挡通行。

## 室内随机箱子

房屋统一提供三个 `LootSockets` 标记，避开桌子、墙体和门洞。三维复核场景随机挑选房屋与室内标记，使用现有 10 个补给箱、7 个普通宝箱的预算，一栋屋里至多放一个箱子；复核种子固定以便重复检查。当前没有高塔，因此不额外摆放城堡宝箱。靠近后按 E 可检查，已检查的箱子变矮，不重复触发；复核入口不发放正式奖励。

二维完整试玩的实际箱子生成也加入室内候选点，约半数尝试优先从房屋内部选择，仍需通过墙体净空、650 间距和高塔预留区检查。失败时继续尝试其他位置，实际室内占比不是固定 50%。总数与掉率沿用上一轮平衡，不通过新增房间额外堆箱子。

## 优化与验证

- 苔石村的独立入口和合并入口共用 `taishi_module`，只组装一份布景。
- 相同尺寸的方块共用不可变 BoxMesh，相同纹理/颜色/缩放的表面共用材质。
- 每个区域密集草丛使用 MultiMesh，树木共用一份人物防遮挡材质。
- 合并入口只有一个玩家、一台跟随镜头和一套交互；各区域内容不自带第二套控制器。
- `house_entry_checks.gd` 从室外地面连续走入并穿过四种房屋，不再跳过门槛。
- `region_review_checks.gd` 逐栋走入全部 44 栋房屋并检查室内遮挡、随机箱子和重复搜查限制。

本轮最后一次完整检查共 487 项通过，包括主菜单进入/返回复核场景的流程。

复核图位于 `outputs/region-review-0.png` 至 `region-review-5.png`，室内图为 `outputs/region-room-loot.png`。区域 GLB 通过 `tools/export_region_models.gd` 重新导出，共享房屋通过 `tools/export_village_models.gd` 导出；导出模型不包含碰撞与交互逻辑，运行时仍以对应场景/脚本为准。
