# 掉落平衡与区域模型

用户本轮提出九项调整。开局仍选择一把武器，局内最多同时装备三把；验证了搜集武器后能填满第二、第三槽。

## 当前可调平衡值

| 项目 | 本轮实现 |
| --- | --- |
| 武器掉率 | 补给站 12%、宝箱 25%、BOSS 50%；普通怪物不新增武器掉落 |
| 数量 | 每周期 10 个补给站、7 个散布宝箱，另有 1 个城堡宝箱 |
| 间距 | 普通补给站和宝箱之间至少 650 个地图单位；不为凑数放到重叠位置 |
| 防护装备 | 每次宝箱开启总计 2% 概率掉出一套生化服或消防服，不是每套各 2% |
| 电动车 | 每处聚落初始化一辆，六处聚落共六辆；车辆分别保存剩余电量，停放位置不随周期重置 |
| 售卖柜 | 每周期随机三处不同聚落内各一个，不再散布在全地图，仍遵循地图不自动标记的探索规则 |
| 锻造房 | 四处聚落各一个 |
| 附魔 | 用户已确认：每把武器的每种元素最高 5 级，升级和合成继承都封顶；满级不再扣材料 |
| 元素材料 | 普通怪物死亡时，每种已实现元素独立判定：对应领域外 5%、领域内 30%，每次成功掉 1 个 |

未指定的掉率和密度是本轮可调参数，并非宣称已经完成长期平衡。2% 防护装备和 5%/30% 材料率遵循用户要求；5 级上限由用户进一步确认。

电池道具对正在骑乘或身边停放的实际车辆充电；附近无车时不能消耗电池，避免充入一个未关联车辆的界面数值。

宝箱掉出的防护服放入拥有列表，需在 Tab 中穿戴；仍只允许一个防护槽。若随机到的套装已拥有而另一套未拥有，改发尚未拥有的一套，两种都拥有时不会凭空增加防护槽。原生化服和消防服的固定拾取点继续保留。此前难找的原因是服装只在固定坐标，并非原本就能从箱子搜出。

材料以**怪物死亡位置**判断领域，不以玩家位置判断。硫酸池桥面和岸边属于安全地面，按领域外处理；地牢按领域外处理。取消站在领域里每两秒自动获得材料，以及箱子必给毒、火材料的旧规则。BOSS 的既有固定元素奖励独立保留；掉落物在接近后拾取，地牢中同样可拾取。

附魔种类容量仍按原星级规则；本轮限制的是每种元素强化等级。当前只制作毒和火，不新增其他元素地图。

## 炮台修复

原装置绘制位于地表表现层，与地牢地板相同层级，地牢地板会盖住新部署的炮台。现将炮台、诱饵和掉落物拆到 `scripts/presentation/device_visual.gd`，在地表和地牢都绘制于地板上方。技能部署与攻击逻辑仍在 `active_skills.gd`。

进入地牢及切换房间仍清理上一空间的部署物，炮台不会从地表直接传送进地牢；在新房间重新施放后应可见并正常攻击。

## 模块边界

`scripts/growth/loot_rules.gd` 集中维护概率和数量；`scripts/world/facility_placement.gd` 负责生成和间距；`scripts/world/vehicle_fleet.gd` 保存停放车辆与电量。搜刮和击杀入口调用这些模块，界面不自行决定掉落。

## 五处区域的第一批模型

后续复核版已将这五处区域扩至每处 7—8 栋房屋，并与苔石村组成同一三维复核场景；本节记录第一批模型的制作起点。当前规模和入口以《区域复核与目录》为准。

用户指出得对：此前只有苔石村样板，其他区域尚未制作。本轮补做可复用地标组合：

| 区域 | 新模型组合 |
| --- | --- |
| 风车集镇 | 石造风车塔、四组木帆叶、市场摊棚、商铺 |
| 东岸旧街 | 沿岸房屋、石码头、木栈桥、系船柱、仓储木箱 |
| 南部农庄 | 农舍、粮仓筒仓、干草捆、田垄、作物和围栏 |
| 荒草聚落 | 废弃门墙、苔藓、碎石、倒梁与旧屋 |
| 断桥街区 | 河谷、石岸、断开的桥面、桥栏及可通行的替代木桥 |

在 Godot 打开 `scenes/regions/region_gallery.tscn` 按 F6，数字 1—5 切换，WASD 移动，Q/E 调整镜头。房屋和树木继续复用已采纳的模型组件与遮挡机制。风车塔、筒仓、残墙有实体碰撞；码头边界阻止走入水中；断桥缺口不可穿越，替代木桥可通行。

五个区域各有独立 `.tscn` 入口；`scripts/regions/region_module.gd` 构建地标组合，展示控制由 `region_gallery.gd` 管理。`assets/regions/models/` 保存五个可编辑 GLB 交换模型，Godot 执行 `--headless --path . --script res://tools/export_region_models.gd` 可重新导出。GLB 只导出可见几何和材质，碰撞与逻辑仍由场景维护。

这些是区域地标的第一批模型，尚未达到苔石村的完整布景密度，风车帆叶目前静止。完整三维地图的道路、地形过渡、元素领域、高塔城堡和战斗接入仍待继续制作，不能把五个展示模块当作完整地图已完成。

## 验证

`tests/balance_checks.gd` 检查一把开局/三槽装备、概率边界和完整区间、补给密度、防护服真实宝箱获取、车辆电量、附魔封顶、材料位置判定与地牢炮台攻击及绘制层。`tests/region_checks.gd` 检查展示场景、塔/筒仓/残墙碰撞、水岸边界、断桥阻挡和替代桥通行。均已加入项目检查脚本。

最后一次完整检查为 370 项通过。验证期间 growth 检查的所有断言通过后，Godot 无界面进程曾在退出阶段出现原生访问冲突（退出码 -1073741819）；独立复测及最终完整检查正常退出，原生退出问题尚未定位，日志保存在 `logs/growth-debug-1-runtime.log`。没有将失败退出按通过忽略或加入自动重试。
