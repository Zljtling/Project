# 开局流程与随机地图

用户确认：每局地图重新排列；本局内村镇和道路稳定，周期只迁移元素领域、高塔、补给箱等动态对象。玩家在地图中主动选择出生区域，毒、火危险领域内部不可出生。初始武器只选择一把，其余局内搜集，最多装备三把。

## 体验入口

在 Godot 按 F5 运行完整试玩：

主菜单“开始游戏” → 备战选择三个技能及一把初始武器 → “开始逃离” → 暂停地图选择出生标记 → “确认出生” → 开始移动、战斗和计时。

地图上的青绿色圆点为经过校验的村镇/野外出生点，选中后显示金色圆环与区域名称。危险区域内部无可选出生点，即使硫酸池内部有安全桥，也不提供出生点。地图不泄露补给箱、普通宝箱和售卖柜的位置。Esc 在出生页返回备战，在备战页返回主菜单；其他游戏菜单快捷键不能绕过出生流程。

开局期间人物及战斗 HUD 隐藏，世界树暂停，敌人、生存计时、世界周期与技能/冲刺冷却均不推进。确认后显示人物与 HUD。初始武器放入第一个槽，另外两个槽为空，背包也仅持有这一把武器。已选技能保留。

**本轮接入现有完整二维试玩。已采纳的三维模型样板仍在 `scenes/regions/taishi/taishi_village.tscn` 独立运行，完整地图尚未替换成三维美术。** 本轮没有复制三维版本的装备、战斗或开局逻辑。

## 职责划分

| 文件 | 职责 |
| --- | --- |
| `scripts/progression/run_setup.gd` | 主菜单、备战、出生选择、游玩四个开局状态，控制转换与提交出生 |
| `scripts/ui/run_setup_panel.gd` | 构建开局界面，提交玩家选择 |
| `scripts/ui/world_map.gd` | 共用地图绘制，出生模式提交候选点编号，普通模式设置路标 |
| `scripts/world/world_layout.gd` | 带种子的聚落排列、房屋几何、稳定道路及寻路 |
| `scripts/world/spawn_locations.gd` | 生成村镇/野外候选点，检查危险领域、墙体、高塔、敌人和设施占地 |
| `scripts/run/run_flow.gd` | 调用地图生成与动态设施初始化，保留完整游玩规则 |
| `scripts/growth/run_progression.gd` | 原子设置一把初始武器并通知武器系统 |

界面不直接生成地图或推进世界计时；出生校验不依赖界面。确认出生时再次校验候选点，避免生成时有效、提交时已失效。`start_run()` 保留为底层启动仿真的接口，用于既有规则测试；正常玩家入口通过开局控制器提交出生，不能从界面跳过。

## 当前生成范围

保留 8000×6000 地图、六处聚落与 24 栋可进入房屋。聚落名称/区域身份在六个受约束的布局槽位间按种子重排，各槽位位置有随机偏移；这不是任意地形生成器，也尚未改变各聚落内部四栋房屋的平面布局。不同种子改变排列与位置，相同种子复现聚落和初始领域。

道路从共用静态墙体寻路网格生成，连接六处聚落并闭合为环。本局道路数据保持固定；高塔迁移只更新实体墙体与实时寻路，避免道路随倒计时改道。地牢入口继续固定在本局的原入口位置，跨局入口随机化尚未加入。

初始领域和设施在生成聚落后重建；补给箱可继续位于房屋内。候选出生点排除地图边缘、墙体、高塔占地、领域及其缓冲区、附近敌人与设施。区域有部分被领域覆盖时，只在该区域仍安全的位置提供出生标记。

## 验证

`tests/setup_checks.gd` 覆盖主菜单与备战流转、初始武器选择、种子复现、道路连接、危险区域排除、暂停和冷却冻结、关闭/返回操作、越界选点、确认时复检、唯一初始武器、技能保留及周期后地图稳定等行为。已纳入 `tools/check_project.ps1`。

有图形设备时执行 Godot `--path . --script res://tests/setup_checks.gd -- --capture-setup` 可导出出生页与备战页截图至 `outputs/`，并检查地图点击命中。正常启动无需这些测试参数。
