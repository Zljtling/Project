# Elemental Survival 游戏设定

更新日期：2026-11-02  
阶段：三阶段完整流程原型已完成；本轮按试玩反馈扩大地图并重做高塔与探索规则。

本文记录本次讨论的设计决定，作为后续 Godot 制作的依据。继续讨论时同步更新，避免只依靠聊天记录。

状态说明：

- **已确认**：用户明确提出或通过的方向、规则。
- **暂定**：已初步通过、需要原型验证的参数。
- **待讨论**：尚未确认的细节或建议，不作为制作时的既定要求。

## 1. 游戏定位（已确认）

### 正式场景表现方向（2026-11-02 新确认）

世界主题为“被元素灾变侵蚀的村镇与遗迹”。用户确认采用立体建筑与地形、像素人物的组合，参考《八方旅人》的空间与像素质感；下文对纯 Godot 2D 的描述记录旧原型实现，不再限定正式场景技术路线。首先以独立“苔石村”样板验证 3D 建筑、倾斜俯视镜头、像素角色与进屋遮挡，然后逐步迁移玩法。首批样板及模块边界见《苔石村场景样板》。用户明确要求保持逻辑清晰、避免堆砌代码。

第二轮美术反馈：用户认可整体表现，要求增加模型数量、细化粗糙造型，并为遮挡人物的树木添加防遮挡。用户提供八张参考图，偏好成簇像素树冠、自然草地与石路、带门窗/招牌/雨棚细节的建筑；以此细化本作风格。苔石村第二版增加建筑和道具变体，树冠采用人物周围局部透视，树干实体保留。

第二版验收：用户明确确认“这版建模可以采纳”，作为后续场景制作的美术与模型基准。后续继续讨论完整地图布局与制作顺序；这次采纳不表示完整地图、正式角色动画或战斗迁移已完成。

俯视角、2.5D 表现的类幸存者动作游戏。玩家在一个随时间不断变化的超大地图中，抵挡怪物、搜刮零件、寻找设施、利用场景与元素领域，集齐三个不同的关键部件，最终进入地牢寻找出口，逃离这个“移动”的世界。当前以 Godot 2D 实现移动与战斗，用墙体立面、台阶、屋顶遮挡和地面阴影表现高度。

体验参考：

| 参考方向 | 希望获得的体验 |
| --- | --- |
| 《土豆兄弟》 | 清理大量小怪的割草感；像素或简笔画风的视觉方向 |
| 《求生之路 2》 | 战斗中的紧张感，以及根据玩家状态调整敌人压力的思路 |
| 《哈迪斯》 | 俯视角战斗与 2.5D 空间表现参考；正式素材的投影角度待美术阶段确定 |

这些是体验与表现参考，不表示照搬参考游戏的具体规则。

本作主要创新在场景交互：场景影响路线、生存与战斗策略；玩家可以通过装备准备和引导敌人，把危险环境转化为优势。

首版为单人游戏（已确认）。当前设计与制作范围按一名玩家确定；多人合作未列入首版要求，未来是否支持尚未决定。

首版面向 Windows 电脑，使用键盘鼠标操作（已确认）。其他平台与输入方式留待后续考虑，不作为首版交付要求。

## 2. 核心循环（已确认）

观察世界变化倒计时与地图线索 → 选择目的地 → 边战斗边搜刮 → 寻找锻造房、装备房等设施 → 利用装备与元素领域增强战力 → 应对场景变化并迁移 → 集齐关键部件 → 进入最终地牢寻找出口。

世界变化倒计时结束后，游戏继续进行，不进入统一的暂停升级或装备购买阶段。

### 主菜单、备战与出生选择（已确认，已接入完整试玩）

完整开局流程：主菜单点击“开始游戏” → 进入备战界面，选择三个主动技能和一把初始武器等配置 → 点击“开始逃离” → 进入游戏界面并保持暂停，弹出本局地图，询问出生区域 → 玩家选择后在目标区域出生，开始本局。

用户已明确选择每局只携带一把初始武器，其余武器在局内搜集；最多同时装备三把的规则保留。正常玩家入口已替换为这一流程，第一槽装备所选武器，另两槽为空。

用户进一步明确：不允许主动选择毒、火等危险领域内部出生。现提供通过校验的村镇及普通野外标记，点击后高亮并确认出生；Esc 返回备战，备战页可返回主菜单。出生确认前不推进敌人、世界周期、技能冷却与生存计时。出生界面只负责选择并提交区域，不直接修改世界计时或生成整张地图。区域内落点排除墙体、危险领域及缓冲区、高塔和附近敌人/设施；确认时再次校验。模块与实现范围见《开局流程与随机地图》。

## 3. 单局时长与周期

| 项目 | 状态 | 当前设定 |
| --- | --- | --- |
| 成功逃离的目标时长 | 已确认 | 40～60 分钟 |
| 世界变化周期 | 已确认 | 固定周期，不随进程逐轮缩短 |
| 单周期长度 | 暂定 | 约 6 分钟 |
| 变化预警 | 暂定 | 周期最后 45～60 秒 |
| 到时是否强制结束 | 待讨论 | 40～60 分钟目前是体验目标，尚未确定硬性截止时间 |

预警应让玩家有时间安排撤退、赶路或继续冒险。具体警示形式、各场景变化耗时及周期内 BOSS 出场时机待讨论。

## 4. 地图与世界变化（已确认）

地图保留部分地标和连接区域，其他场景随周期发生变化。变化应有可辨认的预告，让玩家能够提前规划。

### 每局生成与局内迁移（已确认，已接入完整试玩）

每次开局重新排列地图中的区域；进入本局后村镇与连接道路保持稳定。倒计时触发的是元素区域、高塔、补给箱等动态对象的迁移，不是再次重排整张村镇地图。已有设施搬迁与地牢入口本局固定的规则继续保留。

当前实现：每局通过种子在六个受约束的布局槽位间重排聚落身份，并随机偏移位置，生成稳定的连接道路和安全出生候选点。各聚落内部暂时保留四栋房屋布局，三维美术尚未迁入完整地图。相同种子可复现聚落与初始领域；地牢入口仍在原入口位置，本局不随周期移动，跨局入口随机化待细化。

初始场景构想：

- 高塔可以提供暂时的地形优势。周期结束后，高塔缓慢下陷、闪烁并消失，塔上的玩家被迫离开，寻找新的场景。
- 补给站随周期重新分布，提供新的搜刮目标。
- 元素领域为路线选择、武器附魔和环境杀敌提供条件。
- 地图中有锻造房、装备房、万能售卖柜等设施，具体功能与刷新规则待细化。

### 试玩修订：大地图与探索（2026-11-02）

- 扩大元素领域，让领域成为可以在内部移动、战斗和利用环境的区域。
- 地图增加房子、巷子和村庄，参考吃鸡游戏的探索感；增加补给站数量。
- 地表地图的自动标记只包括：地牢入口、元素领域、追猎者位置、特殊高塔、锻造房。宝箱和补给站即使靠近发现，也不会自动标在地图上；售卖柜和停放的载具也不自动标记。
- 玩家位置与手动路标属于导航界面。寻龙尺主动探测到的宝箱是宝箱隐藏规则的例外。
- 本轮原型参数：地图 8000×6000，约为旧版面积的 9.7 倍；毒、火领域半径均为 1000；6 处聚落、24 栋可进入房屋；每轮 10 个补给站、7 个散布宝箱，另有城堡固定宝箱 1 个（按最新密度反馈下调）。尺寸、密度和奖励仍可根据试玩调整。
- 村庄街巷与连接道路暂作稳定骨架；设施与领域仍随周期迁移。屋顶靠近时透明，玩家和怪物使用相同的墙体与通行口；墙体会阻挡自动攻击选敌和弹道。

### 高塔城堡（已确认）

高塔是较大的可探索区域，类似城堡。玩家通过移动直接进入，不需要按 E 上塔；怪物也能走入并追击。高塔不再提供旧原型的地面接触免伤、近战停用或远程射程加成。每座高塔固定配置一只精英和一个宝箱。

本轮用 960×880 的城堡庭院、四向城门、台阶和内部房间验证通行。精英具有预警重击，可通过冲刺躲避；不是周期 BOSS，不占周期 BOSS 名额，也不掉落神迹拼图或关键部件。

周期预警与下陷保留：最后 60 秒预警，到时闪烁下陷 8 秒，旧城堡消失并在另一处出现。旧位置的连接地表保留，仍在城堡里的玩家回到同一位置的地表，不通过 E 撤离，也不会被传送到新城堡。存活的固定精英随城堡迁移并保留伤势；已被击杀时，新城堡生成一只新精英。新周期城堡宝箱补满，旧扫描标记清除。这些迁移细节属于本轮可调实现。

### 跨周期状态

| 对象 | 当前规则 |
| --- | --- |
| 玩家 | 保留，不随世界变化重置 |
| 身上装备 | 保留 |
| 怪物 | 保留，不能依靠周期结束清空威胁 |
| 关键路标 | 保留 |
| 补给设施与库存 | 原设施消失，在随机位置重新出现，库存恢复满 |
| 区域型 BOSS | 随所属领域迁移，保留血量，采用非常缓慢的迁移回血 |

未拾取的地面掉落、已投入设施的材料、放置物及其他持续状态如何处理，待讨论。

## 5. 战斗操作（已确认）

采用混合操作：基础武器自动攻击，玩家手动控制冲刺、主动技能与场景交互。

玩家最多同时装备 3 把武器，已装备武器参与自动攻击（已确认）。备用武器不参与攻击，其携带方式与背包容量待讨论。

默认由各武器自动选择适合攻击的目标；玩家可以临时标记一个优先目标，能攻击到该目标的武器优先集火。目标死亡或玩家取消标记后，恢复自动索敌（已确认）。标记输入方式、目标超出射程或视野后的处理，以及具体索敌优先级待讨论。

主动技能使用 3 个独立技能槽。玩家在开局前自行选择 3 个主动技能，携带进入本局；武器与技能分别搭配，不强制绑定角色、武器或装备（已确认）。该规则替代此前“在探索中获得并装配主动技能”的初步方向。

三个技能槽自由选择技能类别，不要求“道具”“伤害”“巧劲”各携带一个；可以携带多个同类别技能，也可以混搭（已确认）。能否重复装备同一个具体技能，尚未确定。

开局选定的 3 个主动技能在本局内不能更换；局内通过强化和武器被动改变其效果，不替换技能本身（已确认）。装备房不提供本局主动技能更换功能。

局内通过击杀 BOSS、搜寻宝箱、使用购买的强化道具、使用技能积累熟练度，以及武器强化产生的被动，提升已携带主动技能的效果（已确认）。数值提升、机制变化、武器被动联动三类强化方向均保留。各途径的具体奖励与触发条件待讨论，尚未确定每次击杀、开箱或强化都必定提供技能增强。

开局可选技能池的解锁方式，以及技能的冷却与使用消耗，尚未确定。

冲刺作为独立的基础操作讨论，其资源与无敌时间尚未确定。

### 主动技能的局内强化（已确认）

“寻龙尺”为道具类主动技能，开局可放入任意技能槽，遵循本局不可换技能的规则。基础冷却 20 秒，使用后在地图显示距离玩家最近的 1 个未开启宝箱；本局成功探测 5 次触发“熟能生巧”，从第五次起每次显示最近 3 个未开启宝箱。

本轮探测细节：无距离上限，按直线距离排序；重复使用会更新本次探测结果；标记保留到宝箱被打开、再次扫描或世界搬迁。没有可探测宝箱、或身处稳定地牢时不消耗冷却与次数。少于三个可用宝箱时显示实际数量。降温芯片可正常缩短其冷却，技能奖励不为它生成无作用的伤害或范围升级。后续专属分支另行讨论。

| 强化方向 | 规则 | 用户提出的设计示例，具体内容与数值待测试 |
| --- | --- | --- |
| 数值提升 | 可以通过道具对指定技能进行强化 | 从万能售卖柜购买“降温芯片”，对指定技能使用后减少其冷却时间 |
| 机制变化 | 本局中使用技能达到条件，可触发熟练度成长效果 | 一局内使用诱饵 10 次后触发“熟能生巧”，扩大诱惑范围，并增加爆炸效果 |
| 武器被动联动 | 武器的被动根据主动技能类别产生不同效果，适用范围按每把武器单独定义 | “青龙偃月刀”升至三星后，对“道具”类技能提供释放后持续 5 秒的移速提升；对“伤害”类技能提供附加攻击，使敌人持续 5 秒减速并持续扣血；对“巧劲”类技能不生效 |

“道具”“伤害”“巧劲”是当前提出的技能类别，完整分类与各技能归属待讨论。“青龙偃月刀”的例子不代表其他三星武器也不能影响“巧劲”类技能，也未规定所有武器都在三星以相同方式获得被动。

熟练度成长按本局使用技能的条件触发。有效使用如何判定、是否允许空放计数、是否有多个成长阶段、达到条件后如何反馈，以及使用次数阈值，尚未确定。示例中的 10 次与 5 秒均不是所有技能或武器的通用规则。

### BOSS 与宝箱的技能强化选择（已确认）

- BOSS 或宝箱提供技能强化奖励时，生成 3 个适配当前携带技能的随机选项，由玩家选择 1 个。
- 允许刷新选项，付费刷新消耗金币。
- 部分道具或技能可以提高免费刷新次数。

每次刷新费用、是否递增、免费次数的适用范围与恢复时机、选项重复规则、与熟练度成长的关系，以及选择和刷新界面是否暂停，尚未确定。该规则不代表每个 BOSS 或宝箱都必定提供一次技能强化。

### 管理界面与暂停（已确认）

- 打开背包、附魔界面或锻造界面时暂停游戏，敌人、世界变化倒计时和战斗效果一起停止推进。
- 赶往设施、接近设施及完成交互以打开管理界面之前，游戏保持实时，路途与抵达过程仍有压力。
- 快捷施放冲刺与主动技能不触发暂停，保持战斗连贯。

这是由玩家打开管理界面触发的暂停，与世界变化周期结束后不进入统一暂停阶段的规则兼容。本轮按用户授权采用推荐方案：地图、商店和技能强化选择界面也暂停；M 打开或关闭地图，技能栏显示图标、按键和剩余冷却秒数。

### 防护装备（已确认）

玩家拥有 1 个防护槽，一整套防护装备占用该槽。例如生化套装作为一件完整装备穿戴，提供已确定的毒气免疫效果。

首版采用整套防护装备，不拆分头盔、上衣、鞋子等部位，也不要求收集多个部位来激活套装。获取方式、换装规则、不同防护装备的具体效果与数值待细化。

### 武器星级与合成（已确认）

同一把武器可以叠加多种元素附魔，容量由武器星级决定。

| 星级 | 附魔容量 | 获取方式 |
| --- | --- | --- |
| 一星 | 最多 1 个附魔 | 初始获取途径待讨论 |
| 二星 | 最多 3 个附魔 | 3 把一星武器合成 1 把二星武器 |
| 三星 | 附魔无上限 | 3 把二星武器合成 1 把三星武器 |
| 四星 | 附魔无上限 | 对三星武器使用“神迹拼图”，破格进化 |

一星升二星、二星升三星时，使用一把主武器加两把任意同星武器，不要求同名；结果保留主武器类型并提升一星（已确认）。材料武器作为合成投入，不额外产出其他武器。

合成时保留主武器的附魔，并合并继承两把材料武器的附魔；三星使用神迹拼图突破四星时也保留已有附魔（已确认）。同一种元素在投入武器上重复出现时，合并强化对应元素附魔，不仅去重（已确认）。

附魔强化等级与武器星级分别记录。除武器合成外，玩家也可以消耗对应元素材料重复主动附魔，强化已有的同元素附魔（已确认）。每种元素强化等级已按用户确认限制为最高 5 级，合成继承也封顶；满级后不扣材料。不同等级的进一步效果细节待测试。附魔容量无上限不等于强化数值或等级无上限。

四星武器的伤害和元素伤害大幅提高，以提供明显的后期爽感。具体数值待测试。

武器合成升星与使用神迹拼图突破四星，需要在锻造房完成；添加和强化元素附魔可以随身操作（已确认）。打开相应管理界面时暂停，规则见“管理界面与暂停”。是否有施作时间和额外费用，尚未确定。

锻造操作修订：用户指出必须先装备低星武器才能升级不合理。现已将锻造台目标选择改为全部持有武器，包括背包与已装备武器；升级备用武器后仍放在背包，不自动替换装备。界面显示目标、两把具体材料与结果星级，可手动调整材料；默认仅建议备用武器作为材料，已装备材料需先开启选项再手动选择。附魔合并和四星突破沿用原规则。界面组件独立于合成交易逻辑。

尚未确定：合成费用、附魔以外的属性如何继承，以及元素组合反应和重复元素的具体强化规则。三星和四星的附魔容量均为无上限。

武器强化可出现提升主动技能效果的武器被动（已确认）。具体武器可以根据主动技能类别提供不同联动，详见“主动技能的局内强化”。被动的生成条件、是否占独立词条位置、与元素附魔的关系、合成继承方式，以及每把武器影响哪些技能，待讨论。

## 6. 敌人与战斗节奏（已确认）

小怪数量构成割草体验，基础血量不要过度膨胀，让成长后的装备能够明显提高清怪能力。

精英怪通过各自的攻击逻辑制造紧张感。新周期开始后，精英怪不要立即出现，应留出适应新场景的时间。

每个周期安排一个 BOSS，额外 BOSS 可以由条件触发。BOSS 类型存在随机性。具体出场时间、类型权重、追加条件和同时存活数量上限待讨论。

动态压力需要有积累、爆发和喘息，也要让玩家享受到变强后的优势。具体采用哪些玩家状态、调整哪些刷怪参数，尚未确定。

由于怪物跨周期保留，未击杀的追猎型 BOSS 可能影响后续周期。如何控制连续追猎与怪物积累造成的压力，需要原型验证。

## 7. BOSS（已确认）

采用“部分必须击杀”的方向：普通周期 BOSS 可以绕开，少数持有关键部件的目标 BOSS 有明确标记，玩家需要击杀对应目标取得部件。混合来源下，并非所有关键部件都必须通过战斗获得。

### 7.1 追猎型

- 主动追杀玩家。
- 玩家可以暂时回避，但存活的追猎型 BOSS 会持续形成压力，促使玩家寻找机会处理。
- 必掉大量基础材料。
- 概率掉落 BOSS 相关的强力武器、装备或关键部件。

### 7.2 区域型

- 镇守自己的领域。
- 玩家不进入攻击范围时，不会主动满地图追杀。
- 玩家离开领地后，BOSS 脱战并逐渐回血，防止利用脱战边界无风险磨血。
- 奖励类别与追猎型相近，奖励数量或总体收益更高，鼓励主动挑战。
- 周期变化时，随所属领域迁移，保留当前血量。
- 因领域迁移而触发的回血非常缓慢，避免迁移给玩家造成过大的额外压力。
- 在进入地牢前，击杀镇守某个元素领域的区域型 BOSS，可以获得为武器附加该领域元素的能力。此类能力属于 BOSS 奖励的一部分。
- 击杀非元素镇守型 BOSS，可获得 1 个“神迹拼图”。其镇守场景例如孤塔、核电站、花园迷宫；此类 BOSS 按非元素镇守型处理，不能仅根据场景名称自动归为元素 BOSS。

“神迹拼图”用于将一把三星武器破格进化为四星武器，四星武器的伤害与元素伤害大幅提升。每次突破消耗的拼图数量、是否消耗道具及使用地点待明确。

主动离开领地后的正常回血与领域迁移回血需要分别配置。警戒、追击、脱战边界，以及回血开始和结束的准确条件待讨论。迁移本身是否完全不产生瞬时回血、已发现 BOSS 的新位置如何提示，也尚未确认。

## 8. 元素领域与指素针（已确认）

当前元素构想包括风、火、雷、木、水、毒、暗，最终元素数量与相互反应规则待讨论。

### 毒领域示例

- 无防毒装备的玩家进入毒领域，会中毒，同时可以利用领域为武器附加毒效果。
- 生化套装可以免疫毒气，使玩家更安全地利用领域与附魔。
- 玩家可以把追来的怪物引入毒领域，使其持续受到伤害。
- 带毒武器攻击怪物，也可以使怪物持续掉血。
- 玩家需要根据当前装备与承受能力，决定进入、停留或迁移。

其他元素应各自影响场景利用与战斗选择，具体效果不能直接沿用毒领域的规则。

### 指素针

类似指南针，为玩家指示对应方向上的元素区域，帮助玩家根据装备选择迁移方向。

探测距离、是否显示多个同类领域、是否需要升级、是否显示精确距离，以及世界变化后的信息更新规则待讨论。

直接通过领域接触获得的附魔，其持续时间与离开领域后的保留规则待讨论。武器星级决定附魔容量；具体替换方式和环境对不同怪物的作用待讨论。

### 击杀领域 BOSS 获得附魔能力（已确认）

玩家在进入地牢前，击杀镇守某个元素领域的区域型 BOSS 后，可以获得为武器附加对应元素的能力。例如，击杀毒领域 BOSS 后，获得毒元素武器附魔能力。

该奖励与直接进入元素领域获得附魔是两种获取途径。已确认：获得能力后，玩家在本局中脱离领域仍能主动使用对应元素附魔。同一把武器可以叠加多种元素，容量由武器星级决定，详见“武器星级与合成”。

主动附魔消耗对应元素材料；对已有同元素附魔重复施加，也可以强化该元素附魔（已确认）。添加不同元素仍受武器星级的附魔容量限制。

主动附魔与附魔强化均可随身操作，不要求前往锻造房；打开附魔界面时暂停，敌人、世界变化倒计时与战斗效果一起停止推进（已确认）。具体操作界面待讨论。

重复元素在武器合成中也会合并强化。材料的具体获取途径、每次附魔与强化的消耗量、能力是否跨局保留、附魔持续时间、附魔作用于哪把武器、元素反应规则，以及是否提供防护，尚未确定。

## 9. 移动载具与电池（已确认）

最新实现：每处聚落至少初始化一辆电动车，六处聚落共六辆，各自保存电量与停放位置，倒计时不重置车辆。


加入帮助玩家跑图的移动装备，原始描述为“小电炉”，讨论中按电池驱动的移动载具理解；最终名称和外观待确认。

- 使用受电池限制。
- 电池可以在地图上寻找。
- 载具用于赶路。骑行时不自动攻击，也不能施放攻击或部署战斗装置的技能；上车清除已发射弹道和已部署装置。下车后恢复战斗，骑行仍会受伤。寻龙尺与疾行等当前非战斗操作可用；骑行不会消除上车前已经施加给敌人的持续伤害。
- 玩家可以花钱在万能售卖柜交换电池。

骑乘禁止攻击已确认；载具获取方式、正式速度与耗电、受击表现、停放与跨周期处理的细节仍可继续讨论。

## 10. 搜刮、补给与设施（已确认）

搜刮零件并寻找锻造房、装备房，是玩家成长过程的一部分。万能售卖柜至少提供用钱换电池的功能。

万能售卖柜也可出售对指定主动技能使用的强化道具，例如降低技能冷却的“降温芯片”。商品池、售价与强化数值待确定。

锻造房负责武器合成升星，以及使用神迹拼图将三星武器突破为四星；元素附魔和强化可随身进行（已确认）。

补给采用每周期满库存、随机换位置的规则：

- 原补给站在周期结束后消失。
- 无论上一周期是否拿完，下一周期重新出现时库存恢复满。
- 新位置随机，玩家不知道上一周期某一补给站下一次会出现在哪里。
- 不能通过守在旧补给站位置，持续领取刷新物资。

补给内容、设施分布、货币来源、物价、背包容量和锻造的具体操作流程待讨论。

## 11. 关键部件与时间保底

### 11.1 已确认

- 逃离需要三个不同的关键部件，不采用只凑足通用碎片数量的方式。
- 集齐三个部件后，可以开启最终地牢入口。
- 关键部件同时提升玩家的全属性实力，兼具逃离进度与角色成长价值。
- 部件采用混合来源，结合战斗、探索与制作。
- BOSS 在普通情况下低概率掉落关键部件。
- 随本局总时长推进，提高关键部件获取概率，并提供最终保底。
- 达到保底条件后，给出明确线索与可主动追踪的目标；不能直接无条件发放部件。
- 保底针对尚未获得的部件，避免重复道具阻断进度。
- 保底 BOSS 明确持有所缺部件，仍需击杀才能取得。

### 11.2 暂定分工，具体细节待确认

用户已选择混合来源。讨论中提出以下主要途径，作为后续细化的起点：

| 主要途径 | 对应挑战 |
| --- | --- |
| 目标 BOSS | 准备装备并击杀目标 |
| 危险场景 | 准备防护，规划进入与撤离路线 |
| 特殊设施组装 | 搜集所需零件，找到设施并完成组装 |

本轮原型采用：驱动核心主要由 BOSS 提供；稳相棱镜在毒领域按住 E 提取；校准齿轮在锻造房用零件与元素材料组装。普通 BOSS 也可能掉落其他尚缺部件，允许混合路线。部件单独记录，不占武器或防护槽。

每个部件获得后立即提升已实现的基础属性，包括最大生命、武器与元素伤害、移速，以及攻击、技能和冲刺冷却；重复部件不重复加成。开启地牢不消耗部件，加成在地牢内保留。本轮具体数值与时间保底参数见《第三阶段试玩》，继续作为可调原型参数。

## 12. 最终地牢与撤离

已确认：集齐三个不同的关键部件后，开启最终地牢入口；进入后仍需在地牢中寻找出口逃离。关键部件也提升玩家的全属性实力。

地牢入口固定保留，不随世界变化周期迁移或消失，属于地图中的固定地标（已确认）。入口从开局显示在地表地图，作为固定导航地标。

地牢内部保持稳定，不按大地图的固定周期重组；主要通过机关和敌人形成最终挑战（已确认）。进入地牢前获得的元素附魔能力如何在地牢中使用，待细化。

本轮按用户授权采用推荐方案：入口从开局在地图上显示，集齐部件后抵达并确认进入。进入独立稳定的地牢区域后不能返回地表；地表计时与存活怪物冻结，部件不消耗，成长保留。

地牢原型由三间房组成，包含有限敌人、先预警后生效的机关与最终出口守卫。每间房清理后前往门口交互；最后清理出口大厅后仍需抵达出口交互，才触发逃离成功结算。死亡触发失败结算。房间数量、敌人配置、伤害与撤离耗时继续根据试玩调整。

### 死亡结算与扩展要求（已确认）

首版默认规则：玩家死亡后，本局结束，进入结算，再重新开局。普通死亡规则不附带局内复活；后续可以通过技能等特定机制抵消致死事件。

制作时保留致死判定的扩展点，不能在生命值耗尽时直接、不可拦截地结束本局。处理顺序为：判定致死 → 检查可用的死亡抵消效果 → 若成功则处理效果并继续本局，否则确认死亡并进入结算。

生命值与受伤处理、死亡抵消效果、最终死亡通知及本局结算分别承担各自职责。一次致死事件只确认一次结果，避免同一帧多次伤害重复触发技能或结算。首个原型保留这一最小扩展点，不要求立即制作完整复活系统。

#### 已实现技能：“假死”

本轮按更新的表格与用户确认实现：

- 属于“巧劲”类，需由玩家携带。
- 在将要死亡时自动触发，抵消一次死亡，不先进入结算再复活。
- 不可手动释放；技能槽与输入逻辑需要支持此类自动触发技能。
- 每局只能生效一次。
- 生效时恢复最大生命的50%，隐身与移速+100%均持续8秒。

隐身期间敌人不再追踪玩家，不发动新的定点攻击；此前已预警的范围攻击与环境伤害仍可能命中。假死不提供完整无敌，消耗次数后下一次致死正常结算。它占用一个开局技能槽，骑行时也能自动生效。
