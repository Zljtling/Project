# 美术打磨与战斗可读性

本轮按用户提供的柔和植被、石木建筑和微缩景观参考调整美术方向，继续保留已确认的三维场景＋二维像素角色。参考《我的世界》的方格物品槽、明确边框与合成预览组织 UI，没有复制其材质或图标。仍是本项目的首轮统一风格，尚未达到参考图的建筑复杂度与完整光照细节。

## 实际变化

- 玩家采用白发、青绿外衣、浅披肩和腰包的独立像素图组。
- 普通敌人采用弓背、长臂、苔绿皮肤的感染者造型。
- 追猎者采用红褐兜帽、面罩与双爪；毒镇守者采用宽躯干与菌盖气孔；火镇守者采用岩甲、角和炽热裂纹；中性镇守者采用灰岩配色；高塔精英使用独立头盔、肩甲与盾形轮廓。
- 七套角色图组与四帧步行序列由 `tools/build_art_refresh.py` 可重复构建。角色图组在 `assets/art_refresh`，不再把同一个旅行者精灵放大染色当 BOSS。
- 正式游戏使用正交投影，缩放改为调整正交视野。人物朝向按镜头的屏幕方向选择，移动与战斗仍共用现有平面逻辑。
- 子弹增加实际宽度、暗色外边、明亮弹芯和拖尾；近战挥击与范围攻击增加粗弧线。保留深度测试，墙体不会被子弹视觉穿透。实际伤害、速度、射程没有更改。
- BOSS 攻击和高塔精英重击增加橙色粗线范围预警。
- 宝箱增加箱盖、金色锁扣，附近交互物加入分类标签和地面亮环：宝箱金色、补给浅绿、售卖柜浅蓝、锻造台暖橙。标签只在附近且视线畅通时显示；已搜刮箱子随正式状态隐藏。
- 草地去掉硬边像素噪声，改为低对比连续色调和细草簇。树冠替换为更柔和的分层叶片，建筑贴图使用带 mipmap 的线性过滤，减少远处闪烁。树叶防遮挡继续保留。
- 野外草簇按固定种子生成并批量绘制，避开道路、房屋碰撞和两处元素区域。

## UI 与锻造

主题统一使用深灰绿石板、方角边框和轻微阴影；按钮、下拉框、弹出列表和技能槽共用方格风格。左侧生命与目标面板缩小，减少场景遮挡。

背包武器改成图标卡片网格，卡片显示名称、星级及装备槽。点击卡片仍调用原有装备事务。锻造保留快速下拉选择，同时提供可点击的背包卡片；上方固定顺序显示“目标＋两件材料→成品”预览，再显示材料选择和确认按钮，背包列表放在后面，避免物品多时把合成操作挤到最下面。背包、锻造和售卖界面隐藏测试计时按钮。

升级规则、材料保护、已装备材料手动选择要求，以及升级后保留原装备/背包位置均未更改。

## 验证与预览

原有 570 项回归检查通过；新增 `tests/art_readability_checks.gd` 的 8 项检查覆盖独立角色资源、正交镜头、实际子弹三角形批次、近距离分类标记、远处隐藏、锻造预览顺序和卡片装备事务。

截图：`outputs/game-art.png`、`outputs/game-forge.png`、`outputs/game-inventory.png`。这些是固定种子的调试复核画面，角色站位及附近箱子为展示而安排；正常游戏仍使用原有生成与战斗规则。

F5 后正常开始游戏即可体验。当前火区域与高塔仍保留功能模型，尚未制作参考图那样的大型城堡和多层街区；本轮集中处理角色、植被、镜头、战斗和界面。
