# 正式场景接入与毒元素区域

用户已通过六处聚落复核，授权接入正式游戏，随后先制作毒元素区域。现在按 F5 → 开始游戏 → 备战 → 开始逃离 → 地图选择安全出生点 → 确认出生，即进入三维场景和像素角色的实际游戏。

## 已接入的正式功能

- 六处聚落共 44 栋房屋；地图建筑轮廓、人物移动、敌人寻路与攻击遮挡读取同一批模型碰撞。
- 可从室外连续走进房间，进入后隐藏屋顶与前墙，离开恢复；树叶仍使用人物周围的局部透视。
- 室内箱子使用房屋 `LootSockets`，避开家具和门洞。发放既有游戏奖励，不再是复核场景的空检查；用视线判断阻止隔墙搜刮。
- 保持 10 个补给箱、7 个普通宝箱、1 个高塔宝箱、3 台售卖柜和 4 个锻造台的现有预算；固定复核种子的一局有 6 个室内箱子，实际数量随种子变化。
- 一把初始武器、最多同时装备三把、背包直接锻造、附魔上限 5 级、装备掉落、每村一辆电动车与电量机制沿用原规则。
- 人物、敌人、攻击、落物、炮台、机关提示、部件、地牢门与导航箭头均有三维表现。右键标记通过镜头投射到地面，WASD 按镜头方向移动。
- 地牢保留三间房间与撤离规则，炮台可见且继续攻击。M、Tab、Esc 的暂停行为不变，鼠标滚轮调整镜头远近。

正式入口为 `scenes/game_run.tscn`，二维 `scenes/validation/planar_run.tscn` 保留为规则回归入口；独立聚落复核仍可从主菜单进入。

## 毒元素区域

用户指定内容全部按大型硫酸池实现：

| 内容 | 首版落地 |
| --- | --- |
| 大面积硫酸池 | 约 58×50 米，不规则池岸；绿色酸液、缓慢流动纹理、浅色岸线 |
| 大鹅卵石 | 环池大型灰绿色石群，桥头留通行开口，石群具有实际阻挡 |
| 相连桥梁 | 9 段木桥组成东西主路、北支路和南支路；转弯处在石台上连接，护栏避开交汇口 |
| 池中歇脚石 | 6 块宽阔低石台，桥面之外仍有可停留空间，可行走进入 |
| 毒气泡 | 周期鼓起、上浮并消失的气泡 |
| 毒烟 | 分散烟团约 13 秒一个上升周期，上升、扩散、淡出，保持桥与石面可辨认 |
| 棱镜目标 | 位于北侧池中石台，沿主桥和支桥可到达，按住 E 提取 |

毒烟为环境表现。环境伤害依据玩家脚下是否接触硫酸池，不会因为桥上飘过烟团就额外扣血。安全石台不会自动回血。

伤害、桥网、石台与地图示意共用 `poison_layout.gd`。桥上、石上、外岸安全；走入酸液才开始既有中毒伤害，默认每秒 5 点，生化服沿用免疫。离开酸液重置暴露计时。桥石安全面不提供毒接触附魔；敌人死在毒区桥石上仍按区域内 30% 掷毒材料，区域外为 5%。毒、火区域内继续禁止选作出生点，包括毒池内部的安全石台。

大石与护栏碰撞跟随毒区迁移。斜桥护栏拆成短段投影到平面碰撞，避免整段外接矩形封死斜桥；回归检查会从每座桥的一端连续走到另一端，包含岸边开口和交汇石台。

## 布局与迁移

当前为避免美术模块互相覆盖，六个聚落在上下两排约束位置之间按种子重排身份，位置带小幅扰动；道路在本局保持稳定。毒火区域使用左右两处大区域，初始方位由种子决定，每周期交换；高塔使用中央三处迁移位置。箱子与设施继续在周期中重新分布。

这是当前模型接入阶段的约束布局。后续增加元素区变体时，可以扩充候选区域和轮廓；不是任意叠放地标。原型地图尺寸与生存计时规则保留。

## 代码职责与优化

| 位置 | 职责 |
| --- | --- |
| `scripts/run/game_run.gd` | 正式场景适配、出生前装配、镜头输入与毒区规则连接 |
| `scripts/presentation/runtime_world.gd` | 组合场景、同步设施/载具/地牢、屋顶遮挡与迁移表现 |
| `scripts/presentation/runtime_actor.gd` | 从既有角色状态更新像素精灵和血量提示 |
| `scripts/presentation/runtime_effects.gd` | 将子弹、范围提示、落物与箭头合批绘制 |
| `scripts/world/scene_geometry.gd` | 读取模型中的实体碰撞，转换为现有平面移动与导航几何 |
| `scripts/regions/elemental/poison_layout.gd` | 毒池轮廓、桥网、石台、安全判断，独立于特效 |
| `scripts/regions/elemental/poison_region.gd` | 酸液、石群、木桥、气泡和毒烟模型 |
| `assets/regions/elemental` | 酸液与烟雾着色器 |

战斗、生命、装备、货币和奖励仍使用原有系统，没有在三维角色或箱子上再复制一套。导航网格由 40 调整为正式场景的 20 个玩法单位，避免细门洞被错误封闭。道路合并连续直段，保留已有共享网格、材质与草丛 MultiMesh；动态特效共用一个绘制批次，设施和设备按变化重建。

`tools/profile_runtime.gd` 提供不含渲染的同步模拟基准：本机固定种子、90 敌人、773 段碰撞，180 步中取后 120 步，平均约 5.10 ms，P95 约 6.06 ms。它不包含 GPU 绘制、完整引擎帧或长时间运行，不能当作游戏帧率保证。

## 检查与复核

运行 `tools/check_project.ps1`。原有 487 项检查加正式场景 83 项，共 570 项。新检查覆盖 44 个实际门口的连续通行、所有木桥通行、寻路、出生安全、种子复现、室内真实奖励与重复搜刮、毒区伤害/防护/歇脚点、迁移及地牢炮台伤害。

截图位于 `outputs/game-poison.png`、`outputs/game-poison-close.png`、`outputs/game-room.png` 与 `outputs/game-dungeon.png`。在地图点击毒区设置路标后，可沿角色附近的金色箭头前往，无法选择在毒池中直接出生。

## 高塔设计草案：待下一步细化

高塔目前保留可走入城堡、精英、宝箱和迁移下沉功能，未将下列草案当作已确认的新规则：

1. 轮廓采用高出周围地形的中央塔楼、低矮外墙和破损石基，与聚落屋顶和毒池石群形成明显区别。
2. 地面城堡保留四向宽门与环形回廊，至少两条撤离路线，避免精英守住唯一通道。楼梯可连接低台；是否开放更多楼层另行确定，不能只画楼梯却不可上去。
3. 精英与高塔宝箱放在庭院内有回旋空间的位置；中央塔身不堵住四门之间的通路。
4. 保留周期结束前 60 秒预警与 8 秒下陷。表现可增加塔基裂纹、尘土和逐步下沉；消失时同步清除旧碰撞，新塔出现后再启用新碰撞。
5. 高墙/塔身采用与房屋一致的人物遮挡处理，保持门口、精英预警和撤离路线清楚。它不会自动变成免伤安全屋。

火元素区暂保留灼热地表和伤害提示，未擅自添加新的火区玩法。敌人暂用共享像素人物着色，专属敌人美术、火区与高塔正式建模继续分步制作。
